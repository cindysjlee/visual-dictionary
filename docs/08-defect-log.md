# 결함 기록

개발 중 테스트·smoke·사람 확인이 잡은 결함을 정리한다. 설계를 바꾼 결함은 `07-change-log.md`의 변경 ID(CH-, PR-)와 연결했다.

**근거와 표기**
- 근거: git 커밋 메시지, 개발 대화 기록(사용자 보고와 세션 요약의 "Errors and fixes" 절, 읽기만 함), 테스트·smoke 출력.
- 날짜는 고친 커밋의 날짜(한국 시간)다. 커밋이 개발 중 수정이라 따로 없으면 그 기능의 커밋을 적고 "(개발 중)"으로 표시한다.
- 발견 방법: **단위**(Vitest), **인프라**(CDK assertions), **E2E**(Playwright), **smoke**(배포 후 스크립트), **check:aws**, **CI**(GitHub Actions 관문·E2E), **배포**(CloudFormation), **사람**(사용자 화면 확인·검수), **검토**(코드·설정을 읽다가 발견), **측정**(번들·Lighthouse 등).
- 근거를 찾지 못한 칸은 "근거 없음"으로 적었다.
