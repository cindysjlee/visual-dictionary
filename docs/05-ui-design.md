# UI 설계

화면 시안 원본: `docs/design/C2-*.dc.html` (라이트·다크 각각 홈, CSRF 상세).
이 파일들은 디자인 도구용 프로토타입이라 그대로 실행되지 않는다. 배치·색·간격·문구를 참고하는 용도로만 읽는다.

## 화면 구조 (IA)

| 화면 | 경로 | 들어가는 것 |
| --- | --- | --- |
| 홈 · 용어 목록 | `/` | 카테고리 탭(전체·웹 보안·네트워크·운영체제·런타임), 검색, 용어 카드 목록, 검색 결과 없음 안내. 로그인 시: 읽음 상태 필터(전체·안 읽음), 진행률 요약, 이어서 볼 용어 |
| 용어 상세 | `/terms/:id` | 용어 이름·개념 설명 → 애니메이션 플레이어(공격 흐름/방어 모드 탭, 재생 제어, 단계 자막·현재 위치) → 방어 방법 → 참고 자료 → 관련 용어. 로그인 시: 읽음/안 읽음 전환 |
| 계정 | `/auth/login`, `/auth/signup`, `/auth/confirm`, `/auth/reset` | 로그인, 회원가입, 이메일 인증 코드 입력(코드 다시 받기), 비밀번호 재설정(이메일 → 인증 코드·새 비밀번호). 아래 "계정 화면" |
| 내 학습 | `/me` | 전체·카테고리별 진행률, 읽은 용어·안 읽은 용어, 계정 설정(로그아웃, 회원 탈퇴 확인) |
| 공통 | | 상단바(로고·메뉴·로그인 버튼 또는 사용자 메뉴·테마 전환), 없는 용어 안내 페이지. 5단계 사용자 메뉴는 이메일과 로그아웃뿐이고, 진행 현황·계정 설정은 `/me`가 생기는 6단계에서 넣는다 |

## 대표 사용자 흐름

1. 홈 접속 → 카테고리 선택·검색 → 결과가 없으면 안내 후 전체 목록
2. 카드 선택 → 상세 진입 → 1단계 장면에서 멈춘 채 설명을 먼저 읽음 → 무대 가운데 큰 재생 버튼(또는 아래 재생 버튼·스페이스)으로 시작하면 끝까지 이어서 재생. 단계마다 자막 길이에 맞춰 기다린 뒤 넘어간다
3. 필요한 단계를 일시정지·이전·다음으로 반복 → 방어 모드로 차단 지점 확인
4. 마지막 단계까지 재생 → 로그인 상태면 읽음 기록 저장, 아니면 로그인 안내 → 로그인 후 상세로 복귀
5. 홈에서 읽음 표시와 진행률 확인 → 다음 용어

## 계정 화면 (5단계)

- **모양:** 가운데 유리 카드 하나(`.auth-card`, 최대 460px). 제목 → 한 줄 안내 → 폼(레이블이 붙은 입력칸, 검색창과 같은 입력 모양) → 오류(`role="alert"`)·안내(`role="status"`) → 주 버튼(`.btn-cta`) → 보조 링크.
- **비밀번호 조건:** 입력하는 동안 "8자 이상 · 영문 포함 · 숫자 포함"을 기호(✓/·)와 숨은 글자(충족/미충족)로 보인다. 색만으로 구분하지 않는다.
- **돌아가기:** 로그인·가입·인증이 끝나면 `?next=`의 사이트 안 경로로 돌아간다(검증은 `docs/03` 2.4). 이메일은 주소창에 넣지 않고 화면 사이에 메모리로만 넘긴다.
- **오류 문구:** Cognito 오류를 한국어로 바꾼다. 로그인 실패는 이메일·비밀번호를 구분하지 않는다("이메일 또는 비밀번호가 맞지 않아요."). 가입 화면만 "이미 가입된 이메일"을 알린다(요구사항).
- **상단바:** 로그아웃 상태면 "로그인" 버튼(지금 경로를 `next`로), 로그인 상태면 이메일과 "로그아웃". 상태를 읽는 동안은 같은 크기의 빈 자리. 휴대폰 폭에서는 이메일을 숨기고 간격을 줄여 한 줄에 둔다.
- **상세 페이지:** "학습 상태" 카드는 로그아웃 상태면 로그인 안내와 버튼, 로그인 상태면 저장 준비 중 안내. 로그아웃 상태로 기본 흐름을 끝까지 보면 플레이어 아래에 "끝까지 봤어요. 로그인하면 … 저장" 안내와 "로그인하고 저장하기" 버튼(로그인 후 그 용어로 복귀). 읽음 저장은 6단계에서 연결한다.

## 디자인 컨셉: Bento Glass

밝거나 어두운 바탕 뒤로 색 번짐(빛)이 천천히 움직이고, 그 위에 반투명 유리 카드를 크기별로 도시락처럼 배치한다(벤토 그리드).
라이트·다크 두 테마를 지원한다. 기본은 OS 설정(`prefers-color-scheme`)을 따르고, 상단바 버튼으로 바꾸면 그 선택을 브라우저에 저장한다.

라이트 장면 면 색(`--scene-object` `--scene-object-dim` `--scene-island`)은 2026-11-19에 한 단계 진하게 바꿨다(전: `#F3F5FB` `#D3D9E8` `#DCE2F0`). 흰 간판·차양 줄·기둥 같은 세부가 바탕과 구분되게 하려는 것이다.

공격 연한 바탕(`--attack-soft`)과 방어 연한 바탕(`--defense-soft`)은 각 색의 12%(라이트)·16%(다크) 투명도로 만든다.

- 공격과 방어는 빨강·초록 대신 **주황·파랑**으로 구분한다. 두 색은 밝기도 달라서 색약 사용자도 구분할 수 있다.
- 카테고리 태그 색: 웹 보안=공격색, 네트워크=방어색, 런타임=보라(`#5B3BB8` / `#C3B2FF`), 운영체제=초록(`#1D6B50` / `#8BE3C6`). 모두 글자색 + 같은 색 12~18% 바탕.

### 유리 카드 (`.glass`)

| 속성 | 라이트 | 다크 |
| --- | --- | --- |
| 바탕 | `linear-gradient(135deg, rgba(255,255,255,0.62), rgba(255,255,255,0.28))` | `linear-gradient(135deg, rgba(255,255,255,0.11), rgba(255,255,255,0.03))` |
| 테두리 | `1px solid rgba(255,255,255,0.75)` | `1px solid rgba(255,255,255,0.14)` |
| 안쪽 빛 | 위 `inset 0 1px 0 rgba(255,255,255,0.95)`, 아래 `inset 0 -1px 0 rgba(255,255,255,0.25)` | 위 `rgba(255,255,255,0.22)`, 아래 `rgba(255,255,255,0.04)` |
| 그림자 | `0 20px 50px rgba(40,50,90,0.14)` | `0 24px 60px rgba(0,0,0,0.45)` |
| 흐림 | `backdrop-filter: blur(28px) saturate(180%)` (둘 다, `-webkit-` 접두사 포함) | |
| 빛 반사 | `::before`로 `linear-gradient(160deg, rgba(255,255,255,0.55) 0%, transparent 38%)` | 같은 방식, 시작 색 `rgba(255,255,255,0.10)` |

- 강조 카드는 같은 유리에 공격색(`.tint-attack`) 또는 방어색(`.tint-defense`)을 살짝 섞는다. 예: 홈의 "이어서 보기" 카드, 상세의 첫 번째 방어 방법 카드.
- 모서리: 큰 카드 30px, 일반 카드 26px, 버튼 14~16px, 태그 999px.
- 유리 효과가 보이려면 뒤에 색이 있어야 한다. 바탕에 큰 원형 빛 4개(주황·파랑·보라·청록)를 깔고 20~28초 주기로 천천히 움직인다. 이 움직임은 장식이라 CSS 애니메이션으로 만들고, 동작 줄이기 설정이면 멈춘다.

### 글꼴

- 본문 **Noto Sans KR**, 숫자·단계 번호·요청 라벨 **Sora**.
- CSP가 `font-src 'self'`라서 Google Fonts 링크는 쓰지 않는다. `@fontsource/noto-sans-kr`, `@fontsource/sora`로 직접 포함한다(기존 IBM Plex는 제거).

### 배치

- **홈:** 4열 벤토 그리드. 1행: 소개+검색(2칸×2줄), 이어서 볼 용어(2칸×2줄). 2행: 진행률(1칸), 분야별 진행(1칸), 카테고리·읽음 필터(2칸). 그 아래 용어 카드 4열, 첫 카드만 2칸.
- **이어서 볼 용어 카드:** 작은 장식 애니메이션을 넣지 않는다. 대신 그 용어의 단계 이름을 번호와 함께 나열하고, 위험 단계는 공격색, 방어 시 차단되는 단계는 방어색 테두리로 표시한다. "방어 모드에서는 n단계에서 차단"도 함께 적는다. 이 내용은 용어 JSON의 `steps`, `defenses[].blockedAtStep`에서 가져온다.
- **용어 카드:** 카테고리 태그, 읽음 표시, 이름, 한 줄 설명, "흐름형 · 5단계 · 방어 2개"처럼 플레이어 유형·단계 수·방어/해결 수. 움직이는 미리보기는 넣지 않는다.
- **상세:** 위에 설명 카드(2/3)와 학습 상태 카드(1/3), 그 아래 플레이어 카드 전체 폭, 그 아래 방어 방법 2칸씩, 참고 자료 3칸, 관련 용어 1칸.
- **플레이어 카드:** 위에 "공격 흐름 / 방어 모드" 탭(방어가 여러 개면 방어 모드일 때 그 아래 방어 기법 선택 칩)과 현재 단계(예: 3 / 6 단계)·자유 시점 버튼 → 무대(3D, 내용은 `docs/06`) → 단계 제목·자막 → 이전·재생·다음 버튼, 단계 수만큼의 진행 막대(누르면 해당 단계로 이동), 재생 속도 선택(`0.75×` `1×` `1.5×` `2×`, `.btn` 모양의 `select`, `aria-label="재생 속도"`, 고른 값은 이 브라우저에 기억), 다시 보기.
- 행위자: 현재 단계에 관여하는 행위자만 진하게(해당 단계 색 테두리, 아이콘 바탕을 단계 색으로), 나머지는 흐리게.
- 방어 모드에서 차단되는 단계: 검사한 곳(없으면 목적지 앞 약 78% 지점)에서 봉투가 멈추고, 방어별 `blockedLabel` 도장이 방어색으로 찍힌다. 재생은 그 단계에서 끝난다. 3D 연출의 세부는 `docs/06`을 따른다.

### 공통 규칙

- 아이콘은 선 형태 SVG를 쓴다. 이모지는 쓰지 않는다.
- 누르는 영역은 44px 이상. 아이콘만 있는 버튼에는 `aria-label`을 단다. 탭·토글은 `aria-pressed`를 쓴다.
- 자막 영역은 `aria-live="polite"`.
- `backdrop-filter`를 지원하지 않는 브라우저에서는 유리 바탕의 투명도를 높여(라이트 0.85, 다크 0.6) 글자가 읽히게 한다(`@supports not (backdrop-filter: blur(1px))`).
