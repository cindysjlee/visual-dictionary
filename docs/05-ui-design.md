## 대표 사용자 흐름

1. 홈 접속 → 카테고리 선택·검색 → 결과가 없으면 안내 후 전체 목록
2. 카드 선택 → 상세 진입 → 1단계 장면에서 멈춘 채 설명을 먼저 읽음 → 무대 가운데 큰 재생 버튼(또는 아래 재생 버튼·스페이스)으로 시작하면 끝까지 이어서 재생. 단계마다 자막 길이에 맞춰 기다린 뒤 넘어간다
3. 필요한 단계를 일시정지·이전·다음으로 반복 → 방어 모드로 차단 지점 확인
4. 마지막 단계까지 재생 → 로그인 상태면 읽음 기록 저장, 아니면 로그인 안내 → 로그인 후 상세로 복귀
5. 홈에서 읽음 표시와 진행률 확인 → 다음 용어

## 계정 화면 (5단계)

- **모양:** 가운데 유리 카드 하나(`.auth-card`, 최대 460px). 제목 → 한 줄 안내 → 폼(레이블이 붙은 입력칸, 검색창과 같은 입력 모양) → 오류(`role="alert"`)·안내(`role="status"`) → 주 버튼(`.btn-cta`) → 보조 링크.
- **비밀번호 조건:** 입력하는 동안 "8자 이상 · 영문 포함 · 숫자 포함"을 기호(✓/·)와 숨은 글자(충족/미충족)로 보인다. 색만으로 구분하지 않는다.
- **돌아가기:** 로그인·가입·인증이 끝나면 `?next=`의 사이트 안 경로로 돌아간다(검증은 `docs/03` 2.4). 이메일은 주소창에 넣지 않고 화면 사이에 메모리로만 넘긴다.
- **오류 문구:** Cognito 오류를 한국어로 바꾼다. 로그인 실패는 이메일·비밀번호를 구분하지 않는다("이메일 또는 비밀번호가 맞지 않아요."). 가입 화면만 "이미 가입된 이메일"을 알린다(요구사항).
- **상단바:** 로그아웃 상태면 "로그인" 버튼(지금 경로를 `next`로), 로그인 상태면 이메일과 "로그아웃". 상태를 읽는 동안은 같은 크기의 빈 자리. 휴대폰 폭에서는 이메일을 숨기고 간격을 줄여 한 줄에 둔다.
- **상세 페이지:** "학습 상태" 카드는 로그아웃 상태면 로그인 안내와 버튼, 로그인 상태면 저장 준비 중 안내. 로그아웃 상태로 기본 흐름을 끝까지 보면 플레이어 아래에 "끝까지 봤어요. 로그인하면 … 저장" 안내와 "로그인하고 저장하기" 버튼(로그인 후 그 용어로 복귀). 읽음 저장은 6단계에서 연결한다.

- **구글 로그인(8단계):** 로그인·가입 카드 맨 위에 "Google로 계속하기"(기본 버튼 모양, 테마 토큰. Google "G" 로고만 Google 고정색) → "구글 로그인과 이메일 가입은 서로 다른 계정이에요…" 안내 → "또는 이메일로" 구분선 → 기존 이메일 폼. 카드 아래에 개인정보처리방침 안내 링크. 콜백 화면은 같은 카드에 "Google 계정을 확인하고 있어요…"(`role="status"`), 실패하면 오류(`role="alert"`)와 "로그인 화면으로" 링크.
- **구글 사용자 탈퇴:** 비밀번호 칸 대신 "Google로 다시 확인" 버튼. 구글 계정 선택을 거쳐 돌아오면 "Google 계정을 다시 확인했어요. 5분 안에 탈퇴해 주세요."와 함께 "탈퇴하기"가 켜진다. 탈퇴 뒤 첫 화면 안내는 로그인 도메인을 거쳐 새로 불러오므로 sessionStorage로 한 번 넘긴다.

## 학습 기록 화면 (6단계)

- **상세 "학습 상태" 카드:** 로그인 상태면 "✓ 읽음" 또는 "○ 아직 안 읽음"과 직접 전환 버튼("읽음으로 표시" / "안 읽음으로 되돌리기"). 끝까지 보면 자동으로 읽음이 된다. 불러오기·저장이 실패해도 재생은 그대로이고 카드에 안내와 "다시 불러오기"만 보인다.
- **홈:** "내 진행률" 카드에 전체 "n / m 용어를 읽었어요"와 카테고리별 막대·숫자(막대는 장식, 숫자를 글자로도). 카테고리 칩 아래에 "읽음 상태" 칩(전체·읽음·안 읽음, 로그인 상태에서만)이 카테고리·검색과 함께 적용된다. 읽은 용어 카드에는 "✓ 읽음" 태그.
- **상단바:** 주 메뉴는 "색인 · 소개", 로그인 상태면 "내 단어장"(현재 쪽은 형광펜 밑줄 + aria-current). 아주 좁은 폭(480px 미만)에서는 로고 글자를 화면에서만 숨긴다.
- **최근 본 용어(7단계, 2차에 "책갈피"로):** 로그인 상태면 색인에서 최근 본 것 중 아직 안 읽은 가장 최근 표제어에 책갈피가 꽂히고, 내 밑줄 장부 아래에 최근 본 표제어 3개를 링크로 보인다. 내 단어장에는 최근 본 용어 10개를 "오늘·어제·n일 전"과 함께 보인다. 30일이 지나면 사라진다.
- **관련 용어:** 상세 페이지의 관련 용어 카드는 JSON에 적은 순서대로, 공개된 용어만 보인다. 없으면 카드를 보이지 않는다.
- **회원 탈퇴:** 비밀번호를 다시 입력해 "비밀번호 확인"을 누르면 Cognito가 확인한 뒤에만 "탈퇴하기"가 켜진다. 누르면 확인 대화상자("정말 탈퇴할까요?", 취소에 기본 초점)에서 "탈퇴"로 확정한다. 되돌릴 수 없는 버튼은 공격색 글자에 굵은 테두리로 구분한다. 탈퇴하면 홈으로 가서 "탈퇴했어요. 계정과 학습 기록이 모두 삭제됐어요."를 보이고 로그아웃 상태가 된다. 실패하면 "계정과 기록은 그대로"라고 알린다.

## 디자인 언어 (2026-11, 랜딩부터 적용 · 2차에서 나머지 화면)

토큰은 `apps/web/src/styles/tokens.css` 한 곳. 기존 색 토큰(공격 주황·방어 파랑·테마)은 그대로 두고 아래를 더했다.

| 무엇 | 토큰 | 값 |
| --- | --- | --- |
| 글자 크기 | `--fs-xs` ~ `--fs-2xl`, `--fs-display` | 13 · 14 · 16 · 18 · 22 · 28 · 36px, 화면용 `clamp(34px, …, 56px)`. 본문 줄 간격 `--lh-body` 1.7, 제목 `--lh-tight` 1.18, 한 줄 길이 `--measure` 68ch |
| 간격 | `--sp-1` ~ `--sp-9` | 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96px |
| 모서리 | `--r-sm` ~ `--r-xl`, `--r-pill` | 10 · 14 · 20 · 28px, 알약 999px (클수록 둥글게) |
| 동작 시간 | `--dur-press` · `--dur-quick` · `--dur-enter` · `--dur-story` | 120 · 200 · 320 · 900ms. 곡선 `--ease-out` `cubic-bezier(.16,1,.3,1)`, `--ease-in-out` |
| 판 | `--surface`, `--surface-raised`, `--line-strong` | 내용을 올리는 불투명 판(유리 아님) |
| 브라우저 기본 표면 | `--focus-ring`, `--selection`, `accent-color`·`caret-color` | 포커스 링·선택 영역·입력 커서도 토큰으로 |

**동작 규칙.** 화면마다 연출은 하나(랜딩은 형광펜 밑줄이 그어지는 순간). 나머지 움직임은 누른 결과를 보여 주는 데만(토글 표시·도장·캡션 교체, Motion). 장식(반짝이·크롬 광택)만 CSS 애니메이션. 동작 줄이기면 장식을 멈추고 상태 전환은 교차 전환(투명도)만 쓴다.

**유리를 쓰는 곳.** 누르는 요소에만: 상단바. 캡션은 판(움직이는 화면 위에 배경 흐림을 여러 겹 두면 느려진다). 내용(장부·시트·카드)은 불투명 판. 유리 위에 유리를 겹치지 않는다(판 위의 토글은 우묵한 홈). `prefers-reduced-transparency`면 불투명 판, `backdrop-filter`가 없으면 `--glass-fallback`.

### 랜딩: 사전 지면 (2026-11-22 확정)

첫인상: **"진짜 사전을 펼쳤다."** 종이 사전의 한 쪽처럼 "시각화 사전"을 표제어로 풀이한다. 데이터는 `/content/index.json`(색인 항목에 `related` 포함)과 예시 용어 `/content/terms/csrf.json`만 읽고, 숫자(표제어 수·분야 수·단계 수·방어 수·진행률)는 콘텐츠와 실제 학습 기록에서만 센다. 코드는 `features/landing/DictionaryPage.tsx`, 스타일은 `styles/dictionary.css`(2차부터 전역), 색은 `tokens.css`의 `--la-*`.

- **쪽 머리:** 사전 이름 · **찾아보기**(검색어를 `/terms?q=`로 넘김) · 표제어 수.
- **표제어 풀이(첫 화면 왼쪽):** "시각화 사전" + `[視覺化辭典] visual dictionary` + 부제 "보안·CS 용어를 3D 장면으로 보는 사전" + 「명사」 + 뜻풀이 ①무엇(분야와 표제어 수) ②공격/방어 비교(예시 용어가 막히는 단계) ③밑줄 긋는 나만의 사전(가입). 버튼 [표제어 둘러보기]·[회원가입](형광펜 바탕) + "가입하면 내 사전에 밑줄이 남아요."
- **그림 1(첫 화면 오른쪽): 움직이는 연필 스케치**(`SketchFigure.tsx`, 상태는 `sketchScene.ts`, three.js·WebGL 없음, 기준 시안 `docs/design/fig1-sketch-prototype.html`의 ②). 윤곽선은 점을 12px 간격으로 나눠 살짝 흔든 선을 두 번 겹쳐 그리고(연필 `--la-sk-pencil`), 면 색은 윤곽보다 (2.4, 2)만큼 어긋나게 칠한 반투명(62%) 형광펜. 선 떨림(boil): 170ms마다 시드가 바뀌어 다시 흔들린다(프레임 3장 순환, 화면 밖·탭 숨김·동작 줄이기면 멈춤). 움직임은 Web Animations API에 `steps(n)` 이징(초당 12장 스톱모션), 봉투·종이비행기·쿠키·동전은 ±7° 흔들리며 포물선으로 난다. 이름표·효과음(휙!·뿅!·착!·쾅!·안 붙어!·짤랑!·스윽)은 손글씨 Gaegu 700(`--font-hand` = "Gaegu Hand"). 빌드할 때 `scripts/subset-hand-font.ts`(build-index가 호출)가 예시 용어 JSON의 그려지는 필드(이름·사이트·화면·라벨·검사 결과)와 그림 고정 - 강조 카드는 같은 유리에 공격색(`.tint-attack`) 또는 방어색(`.tint-defense`)을 살짝 섞는다. 예: 홈의 "이어서 보기" 카드, 상세의 첫 번째 방어 방법 카드.
- 모서리: 큰 카드 30px, 일반 카드 26px, 버튼 14~16px, 태그 999px.
- 유리 효과가 보이려면 뒤에 색이 있어야 한다. 바탕에 큰 원형 빛 4개(주황·파랑·보라·청록)를 깔고 20~28초 주기로 천천히 움직인다. 이 움직임은 장식이라 CSS 애니메이션으로 만들고, 동작 줄이기 설정이면 멈춘다.

### 글꼴

- 본문 **Noto Sans KR**, 숫자·단계 번호·요청 라벨 **Sora**.
- CSP가 `font-src 'self'`라서 Google Fonts 링크는 쓰지 않는다. `@fontsource/noto-sans-kr`, `@fontsource/sora`로 직접 포함한다(기존 IBM Plex는 제거).

### 배치

- **홈:** 4열 벤토 그리드. 1행: 소개+검색(2칸×2줄), 이어서 볼 용어(2칸×2줄). 2행: 진행률(1칸), 분야별 진행(1칸), 카테고리·읽음 필터(2칸). 그 아래 용어 카드 4열, 첫 카드만 2칸.
- **이어서 볼 용어 카드:** 작은 장식 애니메이션을 넣지 않는다. 대신 그 용어의 단계 이름을 번호와 함께 나열하고, 위험 단계는 공격색, 방어 시 차단되는 단계는 방어색 테두리로 표시한다. "방어 모드에서는 n단계에서 차단"도 함께 적는다. 이 내용은 용어 JSON의 `steps`, `defenses[].blockedAtStep`에서 가져온다.
- **용어 카드:** 카테고리 태그, 읽음 표시, 이름, 한 줄 설명, "흐름형 · 5단계 · 방어 2개"처럼 플레이어 유형·단계 수·방어/해결 수. 움직이는 미리보기는 넣지 않는다.
- **상세:** 위에 설명 카드(2/3)와 학습 상태 카드(1/3), 그 아래 플레이어 카드 전체 폭, 그 아래 방어 방법 2칸씩, 참고 자료 3칸, 관련 용어 1칸.
- **플레이어 카드:** 위에 "공격 흐름 / 방어 모드" 탭(방어가 여러 개면 방어 모드일 때 그 아래 방어 기법 선택 칩)과 현재 단계(예: 3 / 6 단계)·자유 시점 버튼 → 무대(3D, 내용은 `docs/06`) → 단계 제목·자막 → 이전·재생·다음 버튼, 단계 수만큼의 진행 막대(누르면 해당 단계로 이동), 재생 속도 선택(`0.75×` `1×` `1.5×` `2×`, `.btn` 모양의 `select`, `aria-label="재생 속도"`, 고른 값은 이 브라우저에 기억), 다시 보기.
- 행위자: 현재 단계에 관여하는 행위자만 진하게(해당 단계 색 테두리, 아이콘 바탕을 단계 색으로), 나머지는 흐리게.
- 방어 모드에서 차단되는 단계: 검사한 곳(없으면 목적지 앞 약 78% 지점)에서 봉투가 멈추고, 방어별 `blockedLabel` 도장이 방어색으로 찍힌다. 재생은 그 단계에서 끝난다. 3D 연출의 세부는 `docs/06`을 따른다.

### 공통 규칙

- 아이콘은 선 형태 SVG를 쓴다. 이모지는 쓰지 않는다.
- 누르는 영역은 44px 이상. 아이콘만 있는 버튼에는 `aria-label`을 단다. 탭·토글은 `aria-pressed`를 쓴다.
- 자막 영역은 `aria-live="polite"`.
- `backdrop-filter`를 지원하지 않는 브라우저에서는 유리 바탕의 투명도를 높여(라이트 0.85, 다크 0.6) 글자가 읽히게 한다(`@supports not (backdrop-filter: blur(1px))`).
