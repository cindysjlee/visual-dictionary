# UI 설계

와이어프레임과 목업 원본은 디자인 캔버스에 있다: https://claude.ai/artifact/AopGSPVwW7HbjwsX1wDTPH (본인 계정에서만 열림)

## 화면 구조 (IA)

| 화면 | 경로 | 들어가는 것 |
| --- | --- | --- |
| 홈 · 용어 목록 | `/` | 카테고리 탭(전체·웹 보안·네트워크·운영체제·자료구조·런타임), 검색, 용어 카드 목록, 검색 결과 없음 안내. 로그인 시: 읽음 상태 필터(전체·읽음·안 읽음), 진행률 요약, 최근 본 용어 |
| 용어 상세 | `/terms/:id` | 용어 이름·개념 설명 → 애니메이션 플레이어(재생 제어, 단계 자막·현재 위치, 방어 모드 토글) → 방어 방법 → 참고 자료 → 관련 용어. 로그인 시: 읽음/안 읽음 전환 |
| 계정 | `/auth/*` | 로그인, 회원가입(이메일 인증 코드 입력), 비밀번호 재설정(인증 코드·새 비밀번호) |
| 내 학습 | `/me` | 전체·카테고리별 진행률, 읽은 용어·안 읽은 용어, 계정 설정(로그아웃, 회원 탈퇴 확인) |
| 공통 | | 상단바(로고·검색·로그인 버튼 또는 사용자 메뉴), 없는 용어 안내 페이지 |

## 대표 사용자 흐름

1. 홈 접속 → 카테고리 선택·검색 → 결과가 없으면 안내 후 전체 목록
2. 카드 선택 → 상세 진입 → 애니메이션 자동 재생(동작 줄이기 설정 시 정지 상태로 시작)
3. 필요한 단계를 일시정지·이전·다음으로 반복 → 방어 모드로 차단 지점 확인
4. 마지막 단계까지 재생 → 로그인 상태면 읽음 기록 저장, 아니면 로그인 안내 → 로그인 후 상세로 복귀
5. 홈에서 읽음 표시와 진행률 확인 → 다음 용어

## 디자인 컨셉: Packet Lab

네트워크 실습실 화면처럼, 어두운 바탕 위에서 요청(패킷)이 행위자 사이를 이동하는 모습이 가장 먼저 눈에 들어오게 한다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| 바탕 | `#0E141B` | 페이지 배경 |
| 면 | `#16202B` | 카드, 플레이어, 입력창 |
| 플레이어 무대 | `#121B24` | 애니메이션 영역 |
| 테두리 | `#2B3A4A` | 카드·버튼 테두리 |
| 본문 글자 | `#E6EDF3` | 제목, 주요 텍스트 |
| 보조 글자 | `#C9D3DD` / `#9AA8B6` | 설명 / 메타 정보 |
| 공격·위험 | `#F5A04A` (주황) | 위험 단계, 공격 메시지 |
| 방어·차단 | `#5CB3FF` (파랑) | 방어 모드, 차단 표시, 링크, 읽음 표시 |
| 일반 단계 | `#8FA3B8` | 위험하지 않은 메시지 |

- 위험과 방어는 빨강·초록 대신 **주황·파랑**으로 구분한다. 색약 사용자도 명도 차이로 구분할 수 있게 하기 위해서다.
- 글꼴: 본문 **IBM Plex Sans KR**, 요청 라벨·단계 번호 **IBM Plex Mono** (실제 HTTP 요청을 보는 느낌).
- 배치: 애니메이션 → 자막 → 컨트롤을 한 덩어리(플레이어 카드)로 묶어 시선이 위에서 아래로 한 번에 흐르게 한다.
- 플레이어 하단에 단계 수만큼 진행 막대를 두고, 막대를 누르면 해당 단계로 이동한다.
- 아이콘은 선 형태 SVG를 쓴다. 이모지는 쓰지 않는다.
- 버튼 등 누르는 영역은 44px 이상. 아이콘만 있는 버튼에는 `aria-label`을 단다.
