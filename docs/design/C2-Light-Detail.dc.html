CSRF

Cross-Site Request Forgery · 사이트 간 요청 위조

로그인된 브라우저는 그 사이트로 가는 요청에 쿠키를 자동으로 붙여요. 공격자는 이 점을 이용해 다른 사이트에서 몰래 요청을 보내게 만들고, 서버는 사용자가 보낸 요청과 구분하지 못해요.

CSRF 토큰 · 5단계에서 차단

서버가 폼마다 예측할 수 없는 토큰을 넣고, 요청에 같은 토큰이 있는지 확인해요. 함정 사이트는 이 값을 알 수 없어서 위조 요청이 거부돼요.

SameSite 쿠키

SameSite=Lax 또는 Strict면 다른 사이트에서 시작된 요청에는 브라우저가 쿠키를 붙이지 않아요.
